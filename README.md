# RespawnProduct

Welcome to the RespawnProduct project repository.

## Overview
This repository contains the codebase for the RespawnProduct system.

## Branch Strategy
- `master`: The primary development branch where features are initially integrated.
- `main`: The stable production branch.

## Project Structure
- `src/`: Source code directory.
- `tests/`: Automated unit and integration tests.
- `docs/`: Project documentation.

## Getting Started
1. Clone the repository.
2. Checkout to the `master` branch.
3. Install dependencies.
4. Run tests to verify setup.
